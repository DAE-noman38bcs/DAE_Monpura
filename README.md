# DAE_Monpura
মডেলটি সংশ্লিষ্ট ব্লকের বিদ্যমান পরিকল্পনা ও হালনাগাদ তথ্যের ভিত্তিতে নতুন অর্থবছরের পরিকল্পনার খসড়া তৈরিতে সহায়তা করতে পারে। সম্ভাব্য কাজ: - ১৫টি ব্লকের জন্য পৃথক পরিকল্পনার কাঠামো তৈরি। - ব্লকের গ্রাম, মৌজা, কৃষক দল ও ফসলের তথ্য সাজানো। - রবি, খরিপ-১ ও খরিপ-২ মৌসুমভিত্তিক শস্য বিন্যাস প্রস্তুত। -
